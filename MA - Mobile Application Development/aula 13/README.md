# Catálogo de Filmes

O `filmski` é um app feito para explorar um catálogo de filmes.
O catálogo de filmes pode ser obtido atráves da API:
```
https://6414e8c38dade07073cb2a6a.mockapi.io/api/v1/movies
```

Esse projeto é desenvolvido utilizando o [`Expo`](https://expo.dev)

# Como Executar

Instale as dependências
```bash
npm install
```

Para rodar o projeto no `Android`
```bash
npm run android
```

Para rodar o projeto no `iOS`
```bash
npm run ios
```

Para rodar na Web:
```bash
npm run web
```
> [!NOTE]
> Lembrando que para rodar na web, precisa executar o comando:
> 
> ```bash
> npx expo install react-dom react-native-web
> ```
